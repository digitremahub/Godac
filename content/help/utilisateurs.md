# Inviter un utilisateur

1. Ouvre **Administration > Utilisateurs**.
2. Choisis **Inviter par email** (compte classique) ou **Chauffeur sans email (badge + PIN)** si la personne n'a pas d'adresse email professionnelle.
3. Renseigne le nom, le rôle (qui détermine les permissions réelles), le service et éventuellement un titre affiché.
4. Envoie l'invitation — un email est envoyé, ou un badge QR est généré à imprimer pour le mode sans email.

Pour un chauffeur en mode badge + PIN : il scanne son badge pour créer lui-même son code PIN à la première connexion, puis s'en sert pour se reconnecter. Tu peux réinitialiser ce code depuis la fiche de l'utilisateur s'il l'oublie.

Seul le rôle **direction** peut gérer les utilisateurs, changer un rôle ou désactiver un compte.
